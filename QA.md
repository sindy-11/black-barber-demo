# Проверка шаблона

Проверено 30 сентября 2026 года.

- `npm run typecheck` — успешно, ошибок TypeScript нет.
- `npm run build` — успешно; главная страница статически пререндерится.
- Установка зависимостей — успешно; npm audit при установке: 0 уязвимостей.
- Проверены размеры 320, 390/426, 768 и 1440 px. Ширина документа не превышает ширину viewport; горизонтального скролла нет.
- Мобильное меню открывается с клавиатуры. Переход «Услуги» меняет якорь и закрывает меню.
- Все внутренние ссылки имеют существующую секцию назначения. На странице один h1.
- Галерея открывает native dialog, фото загружается; Escape закрывает просмотр.
- Фотографии главной страницы загружаются; карта отрисовывается в браузере.
- Проверены сформированные WhatsApp URL: международный номер, кодирование кириллицы и знака «+», название бизнеса, название услуги и имя мастера.
- `tel:` содержит нормализованный номер. Ссылки на Instagram и карту присутствуют.
- Ошибок в консоли браузера при проверке не обнаружено.

Ограничения проверки: реальное сообщение в WhatsApp и звонок не отправлялись — контактные данные демонстрационные. Проверка проводилась в Chromium, включая эмуляцию ширины экрана; отдельные физические устройства iOS/Android не использовались. Публикация в Vercel не выполнялась. Скорость на реальном мобильном интернете не измерялась.
