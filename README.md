# BLACK BARBER

Готовый демонстрационный шаблон барбершопа: Next.js App Router, TypeScript, Tailwind CSS 4 и Lucide. Без базы данных, форм сбора данных и собственного backend. Запись — обычная ссылка в WhatsApp с готовым сообщением. Отправляет сообщение сам посетитель.

## Быстрый запуск

Установите Node.js 20.9 или новее (рекомендуется актуальная LTS-версия). В терминале откройте папку проекта:

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Для проверки production-версии:

```bash
npm run typecheck
npm run build
npm start
```

`npm ci` устанавливает точные версии из включённого `package-lock.json`. Если порт 3000 занят: `npm run dev -- --port 3001`.

## Новый клиент за 10–20 минут

Скопируйте проект без `node_modules` и `.next`. Откройте **data/business.ts**. Большинство изменений делается только в этом файле:

| Что изменить | Поля в business.ts |
| --- | --- |
| Название, монограмма, город | `name`, `shortName`, `category`, `city`, `founded` |
| Заголовок и описание | `slogan`, `description`, `about`, `cta` |
| Телефон | `phone`, формат отображения свободный, ссылка `tel:` очищается автоматически |
| WhatsApp | `whatsapp`, международный номер с кодом страны, без начального 8 |
| Текст записи | `bookingMessage`, `{name}` автоматически заменяется названием |
| Instagram | `instagram` — полный URL; `instagramLabel` — отображаемый ник |
| Адрес и расписание | `address`, `addressNote`, `hours` |
| Карта | `map.latitude`, `map.longitude`, `map.url`, `map.embed` |
| Услуги, цены, длительность | `services`, число в `price`, валюта в `currency` |
| Мастера | `masters` — имя, роль, опыт, описание, фото |
| Отзывы | `reviews` — имя, дата, рейтинг 1–5, текст |
| Преимущества и показатели | `benefits`, `stats` |
| Фотографии | `photos`, `masters[].photo`, `gallery[].src` и `alt` |
| SEO | `seo.title`, `seo.description`, `seo.url`, `seo.locale`, `seo.indexable` |

Координаты являются справочными; после изменения адреса обновите также обе ссылки карты (`url`, `embed`), чтобы маркер и кнопка вели в одно место. Embed-ссылку можно получить через «Поделиться» в OpenStreetMap. Для другого сервиса вставьте его разрешённый URL встраивания.

### Фотографии

Замените файлы в `public/images/`, сохранив имена, либо обновите пути в конфигурации. Пути начинаются с `/images/`, без `public`. Рекомендуемые размеры: hero — 1920×1280; интерьер — 1200×1000; портреты — 800×1000; галерея — от 1000 px по длинной стороне. Поддерживаются JPG, PNG, WebP, AVIF. Next Image оптимизирует локальные изображения, создаёт responsive srcset, резервирует место и лениво загружает второстепенные фото. Главный кадр загружается приоритетно.

Для удалённых фото добавьте конкретный хост в `images.remotePatterns` файла `next.config.ts`. Проще и надёжнее хранить фотографии локально.

Все текущие изображения — демонстрационные стоковые фотографии. Люди на них не являются указанными вымышленными мастерами; кадры в галерее не являются портфолио реального бизнеса. Перед коммерческой публикацией замените **hero, интерьер, все три портрета и галерею** фотографиями клиента. Источники перечислены в `PHOTO-CREDITS.md`.

### Цвета и стиль

В начале `app/globals.css` измените переменные `:root`:

```css
--background: #141413; /* основной фон */
--surface: #1c1c1a;    /* чередующиеся секции */
--foreground: #f5f2eb; /* основной текст */
--muted: #aaa9a2;      /* вторичный текст */
--accent: #c6a47e;     /* кнопки и акценты */
```

Монограмма сайта берётся из `shortName`. Отдельную иконку вкладки замените в `public/icon.svg`. Используется системный шрифт, поэтому сайт не зависит от загрузки Google Fonts. Анимации выполнены на CSS; настройка reduced motion учитывается.

## Vercel

1. Создайте Git-репозиторий из **этой папки**, загрузите на GitHub, GitLab или Bitbucket. `.gitignore` уже исключает зависимости, сборку и секреты.
2. В Vercel выберите **Add New → Project**, импортируйте репозиторий.
3. Framework Preset: **Next.js**. Root Directory — папка с `package.json` (корень репозитория, если загрузили только этот проект).
4. Стандартные настройки: install `npm ci`, build `npm run build`. Output Directory оставьте автоматическим. Переменные окружения не нужны.
5. Нажмите **Deploy**. После сборки Vercel выдаст адрес `.vercel.app`.
6. Впишите окончательный HTTPS-адрес в `seo.url`, проверьте реальные данные и установите `seo.indexable: true`, затем отправьте изменения в Git для повторного деплоя.

Проект подготовлен для Vercel, но не опубликован в аккаунте пользователя. Услуги платформы и домен оформляются отдельно.

### Свой домен

Откройте проект Vercel → **Settings → Domains**, добавьте купленный домен. В панели регистратора внесите **точно те DNS-записи, которые показывает Vercel**; значения зависят от домена. Дождитесь статуса Valid Configuration и HTTPS. При необходимости добавьте `www` и выберите основной вариант с перенаправлением. Обновите `seo.url` на основной домен.

Документация: [Next.js — установка](https://nextjs.org/docs/app/getting-started/installation), [Vercel — подключение домена](https://vercel.com/docs/domains/working-with-domains/add-a-domain).

## Перед публикацией клиенту

Телефон `+7 (700) 000-00-00`, Instagram, отзывы, рейтинг, показатели, имена, опыт, адрес и цены — демонстрационные. Instagram сейчас ведёт на главную сервиса. Укажите реальные данные, проверьте номер WhatsApp на своём телефоне и замените стоковые фотографии. Отзывы выводятся из конфигурации; интеграции с Google/2GIS нет. Индексация демо выключена через robots metadata. После замены данных включите `seo.indexable`.

Open Graph содержит название, описание, URL и локаль. Отдельная картинка для соцсетей не генерируется; при необходимости добавьте реальное фото клиента в `metadata.openGraph.images` в `app/layout.tsx`.

Внешняя карта загружается OpenStreetMap, требует интернета и зависит от доступности сервиса. Кнопка «Открыть карту» работает отдельно от iframe. Запись не резервирует слот автоматически: время подтверждает администратор в WhatsApp.
